# Kieran Code Lexicon 0.1.9：品牌与冒充风险检查

检查日期：2026-10-10。检查对象：Chihang03/vscode-word-translation 的 marketplace 分支、待同步的 master 默认分支、当前发行包及已有 GitHub Release。

## 结论

0.1.8 完成独立品牌整改，0.1.9 在真实菜单核对后将产品名直接加入命令标题。产品名、图标、简介、命令及发行标题统一为 Kieran Code Lexicon（代码词典），在产品说明开头明确独立维护者和社区 fork 身份。原图标、上游商店徽章、继承的赞助配置与旧展示截图不再用于当前产品展示。本次检查未发现新版声明自己是上游官方版本或借用原发布者扩展 ID。

仍不能认定冒充风险已经消除，也不能据此承诺商店恢复。微软公开记录只给出 Impersonation 分类，没有给出触发项；词库原始来源和独立授权仍未核实，旧发行及 Git 历史仍然存在。

## 剩余风险与下一步

1. **商店历史判定尚未解除。** 保留原独立扩展 ID 便于复核与升级；不使用更换账号或扩展标识来绕过移除。应联系 Marketplace 团队请求具体触发项、发布者状态及恢复原条目的条件。
2. **默认分支和旧发行需一起整改。** 本次将 master 与 marketplace 同步；既有 v0.1.4/v0.1.5 附件和 Git 历史保留，但发行说明已明确其性质。历史文件仍可能被下载或搜索引擎缓存，不能只凭新版说明消除全部混淆。
3. **词库来源与授权未完成独立核实。** 674 个词库文件来自上游且本次不修改。上游仓库有 MIT 许可证，不等同于每条词库数据的原始授权已经查明。后续需要向上游核实原始数据来源，或改用来源和授权清晰的词库。
4. **图标和名称没有得到 Marketplace 预先认可。** 新图没有使用原图素材，但采用的是常见翻译符号；没有完成全网图像相似性或商标检索。本次有限名称搜索未得到明确同名 Marketplace 条目，不能作为名称权利可用的证明。
5. **Publisher 主页及旧搜索缓存未完全核验。** 管理页面受限，不能修改或确认后台展示；如有审核指定的整改项，需按回复继续处理。
